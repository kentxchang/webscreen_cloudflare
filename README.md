# 🏫 教室大屏工具（Cloudflare 版）

**一個網頁，就是一整套上課工具。**
專為教室的觸控大屏、電子白板與投影機設計：白板畫筆、計時器、時鐘、抽籤、轉盤、計分板、PDF 講義、網頁、圖片、實物投影、螢幕錄影⋯⋯打開瀏覽器就能用，不必安裝任何軟體。上課的整個畫面（開了哪些視窗、放在哪裡、白板上寫了什麼）都能存到雲端，下次一鍵開回來繼續上。

## 特色

- **免安裝、跨裝置**：Chrome、Edge 打開網址就能用，教室大屏、筆電、平板都可以。
- **為大屏設計**：按鈕大、圖示清楚，支援觸控；工具列平常自動縮到畫面邊緣，不擋教學內容。
- **整個畫面都能存**：白板筆跡、開著的視窗與位置、PDF、圖片、網頁、計分⋯⋯一次存到雲端，下次一鍵還原；還會**自動雲端存檔**。
- **一個畫面＝一堂課**：每堂課可以準備一個「畫面」，課前排好要用的教材，上課直接開啟。
- **可分享**：產生網址與 QR Code，其他老師或學生開啟就看到同一個畫面。
- **管理者密碼保護**：登入管理者才能編輯與存檔；學生或未登入的人以唯讀模式使用，不會改到老師的存檔。
- **完全免費**：架設在 Cloudflare 免費方案，不需信用卡、不需另外申請資料庫。

## 快速上手（教師）

1. **打開網址**（管理者部署後提供，例如 `https://webscreen.xxx.workers.dev`），建議用 Chrome 或 Edge，按 `F11` 全螢幕效果最好。
2. **第一次開啟**時會請你設定**管理者密碼**（至少 4 個字元），之後每次開啟網頁都要輸入這個密碼才能編輯與存檔。
   - 不想登入時，可以按「👀 不登入，以唯讀模式開啟舊存檔」或「✨ 不登入，以唯讀模式開新畫面」。
3. 登入後出現歡迎畫面：
   - **✨ 開新畫面**：從空白畫面開始。
   - **📂 開啟舊存檔**：選一個之前存的畫面繼續使用。
4. 使用**工具列**：
   - 平常工具列縮在畫面左側，只露出一條細邊；**滑鼠移過去或用手指點一下**就會展開。
   - 上方是**釘選的常用工具**（預設：畫筆、計時器、抽籤、PDF），點一下就開啟。
   - 下方是**分類**，點分類會彈出該類全部工具。工具右上角的 ☆ 可以把它釘選到上方。
5. 每個工具都是一個**視窗**：拖曳標題列可移動、拉角落可縮放、**連點兩下標題列**可最大化／還原，右上角是「─ 最小化、□ 最大化、✕ 關閉」。
6. **存檔**：「雲端 → 雲端存」輸入名稱存檔；之後會**自動雲端存檔**（預設每 2 分鐘，有變更才存）。

## 在大屏上進行教學：應用指南

### 課前準備：把一堂課做成一個「畫面」

1. 開新畫面，把這堂課要用的教材先加進管理清單：
   - 「資源 → PDF」：上傳講義、學習單（可一次多個）。
   - 「資源 → 圖片」：上傳教學圖片、題目截圖。
   - 「資源 → 網頁」：加入教學影片（YouTube 網址會自動轉成嵌入格式）、線上測驗、教學網站。
   - 「資源 → HTML」：上傳互動教材、小遊戲。
   - 「資源 → 心智圖」：貼上 AI 產生的 Markdown 大綱，一鍵變成心智圖，上課再補充節點。
2. 只把**一開始要用的**放到畫面上，其他留在清單裡，上課時再「放到畫面」，畫面就不會太亂。
3. 擺好位置與大小，設定計分板組別、待辦清單（今日任務）、跑馬燈（今日提醒）。
4. 「雲端 → 雲端存」存成例如「七年三班 第5課 光合作用」。上課時一開啟，就回到你排好的樣子。
5. 同一份教材要給其他班或其他老師用：按「雲端 → 分享」，產生網址與 QR Code。

### 上課開場

- **時鐘**最大化放在大屏上，學生進教室就知道時間；可開「整點報時」提醒下課。
- **跑馬燈**顯示今日提醒（例如「請拿出課本第 45 頁」）。
- **待辦**列出本節課流程，完成一項勾一項，學生清楚進度。
- **便利貼**貼上今日作業、注意事項或討論題目，用不同顏色區分，字放大讓後排也看得清楚。
- 用「抽籤」或「轉盤」隨機抽人回答複習問題，暖身又公平。

### 講述與示範

- **PDF 講義**：放到畫面後，按 **▶ 播放**進入全螢幕；點畫面左右兩側或用簡報遙控器（PageUp／PageDown）換頁；開 **🔴 雷射筆**指出重點。
- **畫筆**：直接在任何內容上圈選、畫線、寫算式；**僅筆**模式可避免手掌誤觸。用完按 🗑️ 清除。
- **背景底圖**：國語課用田字格示範筆順、英文課用英文四線、音樂課用五線譜、數學課用方格紙。
- **聚光燈**：把其他地方變暗，只露出要講解的那一題，學生注意力更集中。
- **依序呈現**：把要講的教材依順序排好（例如：影片 → 圖片 → PDF → 小遊戲），每一個都全螢幕呈現，用右下角的「下一個」切換，像簡報一樣流暢。

### 小組活動與討論

- **計時器**：設定討論時間（1／3／5／10 分或自訂），最大化顯示大大的倒數環；最後 10 秒每秒提示音，時間到會響鈴並閃爍。
- **計分板**：6 組加減分，搭配音效，適合搶答、小組競賽。
- **抽籤**：設定全班人數，抽過的號碼不會重複，抽籤紀錄會顯示在下方。
- **轉盤**：自訂選項（例如組別、題號、獎勵），轉出結果。
- **骰子／硬幣**：決定順序、數學機率實驗。
- **噪音偵測**：用麥克風偵測音量，綠／黃／紅燈提醒學生控制音量。

### 實作、實驗與作品分享

- **投影**：接 USB 實物投影機或用筆電鏡頭，把學生的作品、實驗過程即時投到大屏上；鏡頭是前鏡頭時按 **↔ 鏡像**讓畫面方向正確。可**凍結**畫面方便講解、**截圖**保存。
- 截下的圖片可以在「資源 → 圖片」上傳，放到畫面上用畫筆批改、評論。

### 課後與延伸

- **錄影**：錄下講解過程（含麥克風聲音），提供請假學生補課或做成教學影片。
- 畫面會自動雲端存檔；下次上課「開啟舊存檔」繼續。
- 「分享」網址可以貼到班級群組，讓學生回家複習同一份畫面與教材。
- 「系統 → 匯出」可下載 JSON 備份；「設定」可查看資料庫空間，刪除不再需要的存檔。

### 範例：一堂 40 分鐘的課

| 時間 | 活動 | 使用的工具 |
| --- | --- | --- |
| 0–5 分 | 開場、複習 | 開啟舊存檔、時鐘、轉盤抽人回答 |
| 5–20 分 | 講解新概念 | PDF 播放＋雷射筆、畫筆圈重點、聚光燈 |
| 20–30 分 | 小組討論 | 計時器 5 分鐘、噪音偵測 |
| 30–37 分 | 小組發表 | 投影展示作品、計分板加分 |
| 37–40 分 | 總結 | 依序呈現本課重點、待辦打勾、自動存檔 |

### 大屏使用小技巧

- 用 Chrome／Edge 按 `F11` 全螢幕，畫面最大、不受瀏覽器工具列干擾。
- 觸控大屏：點一下工具列細邊即可展開；彈出面板點外面就會收起。
- 常用工具用 ☆ 釘選，一鍵開啟。
- 視窗連點兩下標題列最大化，讓全班都看得清楚。
- 第一次使用錄影、投影、噪音偵測時，瀏覽器會詢問麥克風／攝影機權限，請按「允許」。
- 每台電腦的釘選、音效、工具列位置等偏好設定，會記在該台電腦的瀏覽器中。

## 各功能詳細說明

### 管理者密碼與唯讀模式

- **第一次開啟**：引導設定管理者密碼。設定後就固定使用這個密碼管理。
- **每次開啟網頁**：輸入管理者密碼登入後才能編輯與存檔；重新整理頁面不用重新輸入，**關閉分頁就會登出**（登入最長有效 12 小時）。
- **唯讀模式**（不登入，或用分享連結開啟）：
  - 可以使用畫面上的工具：PDF 翻頁、移動視窗、計時器、抽籤、畫筆、把清單中的教材放到畫面上等。
  - 不能存檔、改名、刪除（開新畫面只能從一開始的登入畫面選擇），也不能在 PDF／圖片／網頁／HTML／心智圖／便利貼清單中新增或刪除內容；所有變更都不會存回雲端，重新整理後恢復原狀。
  - 畫面右上角顯示「🔒 唯讀模式｜登入編輯」，按「登入編輯」輸入密碼即可在目前畫面上開始編輯。
- **登出**：「系統 → 設定 → 管理者 → 登出」。
- **安全性**：
  - 密碼檢查與存檔權限由伺服器把關，修改網頁程式也無法繞過。
  - 密碼以 PBKDF2 加鹽雜湊後儲存，資料庫與程式碼中都沒有明碼。
  - 連續輸錯 5 次會暫停登入 60 秒。

### 歡迎畫面

開啟網頁時出現：**✨ 開新畫面**（清空計分板、待辦、便利貼、抽籤、HTML、心智圖、PDF、圖片、網頁）或 **📂 開啟舊存檔**（從雲端存檔清單挑選；🕒 圖示的是自動存檔）。用分享網址（`?screen=存檔編號`）開啟時會直接載入該存檔。

### 工具列

- **釘選區**（上方）：常用工具一鍵開啟，預設為畫筆、計時器、抽籤、PDF。
- **分類**（下方）：點分類會在旁邊彈出該類工具（圖示＋文字），選了工具、點面板外、按 Esc 會自動收起。
- **釘選／取消釘選**：在彈出面板中點工具右上角的 ☆／★。
- **自動隱藏**：不使用時縮到畫面邊緣，只露出一條有藍色把手的細邊；滑鼠移過去或點一下就展開，離開後自動收回。可在「設定 → 自動隱藏工具列」關閉。
- 最上方的 ☰ 可完全隱藏工具列，⇄ 可切換到左、右或底部。
- 視窗：連點兩下標題列可最大化／還原。

### 計時器

- 圓形**倒數進度環**，一眼看出剩下多少時間；最大化時數字與進度環一起放大。
- 預設 1／3／5／10 分鐘，或輸入秒數「自訂」。
- **▶ 開始／⏸ 暫停／▶ 繼續**同一顆按鈕；**↺** 重置回設定的時間。
- 狀態提示：準備開始、倒數中、已暫停、⏰ 時間到！最後 10 秒數字變紅並跳動，時間到畫面閃爍。
- **音效**（🔔／🔕 切換，記在這台電腦）：開始提示音、最後 10 秒每秒提示音、時間到鈴聲（響三次）。

### 時鐘

- **指針時鐘＋數字時間＋日期星期**；最大化時左右並排放大，適合整節課顯示在大屏一角或全螢幕。
- **🔔 整點報時**：整點時播放鐘聲旋律，並敲幾點就響幾聲。
- **🕐 秒針滴答聲**：每秒滴答一聲（適合安靜作答時營造專注氣氛）。
- 音效只在時鐘視窗開著時才會播放；選項記在這台電腦。

### 雲端存檔與分享

- **🆕 新畫面**：清空成新的畫面；目前畫面有尚未存到雲端的變更時會先詢問。
- **雲端存**：已開啟雲端存檔時可按 **更新目前存檔**、按名稱旁的 **改名** 修改目前存檔的名稱；也可輸入名稱 **另存新檔**。
- **雲端讀**：從清單 **載入**、**改名** 或 **刪除** 存檔。改名只修改名稱，不會改動存檔內容與「最後更新時間」。
- **分享**：產生**目前畫面存檔的獨立網址**與 QR Code，開啟後直接載入該存檔（產生前會先把目前畫面更新到雲端）。
- **自動雲端存檔**（設定中選擇：關閉／每 1、2、5、10 分鐘，預設每 2 分鐘）：只有畫面有變更時才存；新畫面會自動建立「自動存檔 日期時間」；右下角會短暫顯示「☁️ 已自動存檔」。關閉網頁前最後一次變更若還沒到存檔時間不會被存到，重要內容請手動存檔。

### PDF

1. 「資源 → PDF」開啟 **PDF 管理圖層**：可一次上傳多個、拖曳檔案上傳，或輸入 PDF 網址（該網站需允許跨網域讀取）。
2. 清單中每個 PDF 顯示頁數與**佔用的資料庫空間**，可個別 **放到畫面／從畫面移除**、**下載壓縮 PDF**、**改名**、**刪除**。
3. 畫面上的 PDF 視窗：頁面自動符合視窗並置中；底部浮動工具列有上一頁／下一頁、縮放、符合、🔴 雷射筆、▶ 播放（瀏覽器全螢幕，Esc 離開），可收合。
4. 換頁：點框架左側 30%／右側 30%，或鍵盤 ← →、PageUp／PageDown（簡報遙控器）。
5. 每頁轉成寬 1024 像素的 JPEG 存在雲端存檔中，一般每頁約 50～450 KB，20 頁講義約 2～9 MB。
6. **超連結區塊**：按工具列的「🔗 設定連結」後，在目前頁面上拖曳拉出區塊並輸入網址（只接受 http、https、mailto，沒寫開頭會自動補 `https://`），每頁可設定多個區塊；設定中點區塊可修改網址、按 ✕ 刪除，按「✓ 完成連結」結束。平常點區塊會在新視窗開啟連結（滑過時淡淡標示，點連結不會換頁）。**下載壓縮 PDF** 時，超連結會寫進 PDF，用一般 PDF 閱讀器開啟也能點。PDF 格式無法指定連結開新視窗，由閱讀器決定：Acrobat、Foxit、預覽程式會另開瀏覽器；Chrome、Edge、Firefox 內建的 PDF 檢視器預設在原分頁開啟，按住 Ctrl（Mac 為 ⌘）再點或用滑鼠中鍵點即可開新分頁。設定連結需登入管理者。

### 圖片

「資源 → 圖片」開啟 **圖片管理圖層**：可一次上傳多張或拖曳上傳；超過 1920 像素或 1 MB 的圖片會自動縮小成 JPEG 以節省空間。清單有縮圖與佔用空間，可個別放到畫面（可拖曳、拉角縮放，可同時放多張）、改名、刪除；圖片右上角 × 只會從畫面移除。

### 網頁

「資源 → 網頁」開啟 **網頁管理圖層**：輸入網址（YouTube 自動轉嵌入格式）或貼上 iframe 嵌入碼。每個網頁可個別放到畫面（可同時多個）、新分頁開啟、改名、刪除。部分網站（如 Google、Facebook、教育部網站）不允許被嵌入，請改按「新分頁」。

### 上傳 HTML

「資源 → HTML」開啟管理圖層：可一次上傳多個 HTML 檔，或貼上原始碼。每個項目可放到畫面、**分享**（開啟並複製獨立網址 `/h/存檔編號/項目編號`，同時顯示 QR Code 方便學生掃描；需先雲端存檔）、改名、刪除。上傳的 HTML 以沙盒方式執行，無法存取本站資料。

### 文字便利貼

「班級 → 🗒️ 便利貼」開啟管理圖層：輸入內容（可多行）、設定字體大小（12–200 px）與顏色（7 種便利貼色或自訂顏色）後按「＋ 新增便利貼」，可建立多張。每張便利貼可**放到畫面**（以視窗呈現，可拖曳、縮放、最大化）、**修改**（載入上方表單，改內容、字體大小或顏色，畫面上的便利貼同步更新）、**刪除**。清單以第一行當名稱。新增、修改、刪除需登入管理者。

### 心智圖

「資源 → 🧠 心智圖」開啟管理圖層（改寫自阿剛老師的「心智圖製作工具」）：

- **新增**：輸入名稱即可建立空白心智圖，再到畫面上手動增加節點；也可以貼上範本格式的內容（或讀取 `.md` 檔）。格式為每行一個節點：`#` 中心主題、`##` 主分支、`###` 子分支，以此類推；`[文字](網址)` 加超連結、`![說明](圖片網址)` 加圖片。點「💡 參考 Prompt」可複製請 AI 產生大綱的提示詞。
- **放到畫面**：以視窗開啟並直接編輯：右側按鈕可新增子節點／同階節點、刪除、超連結、圖片（本機圖片自動壓縮後存在心智圖中）、左右排列、展開／收合、簡報模式、匯出投影片影片；雙擊節點改文字、拖曳節點調整位置、滾輪縮放、拖曳空白處平移；左上角選單可匯入 MD、下載 HTML／PNG、匯出 MD。修改會隨畫面一起雲端存檔。
- **分享**：開啟並複製獨立網址 `/m/存檔編號/項目編號`，同時顯示 QR Code；分享頁面只能瀏覽（可展開收合、簡報模式、下載），不能修改。需先雲端存檔，畫面有未存的變更時會先更新存檔。
- 改名、刪除需登入管理者。

### 依序呈現

「資源 → 📽️ 依序呈現」列出畫面上顯示中的物件（視窗、PDF、網頁、HTML、心智圖、便利貼、圖片），勾選並用 ↑ ↓ 排序後按 **▶ 依序呈現**。物件依序佔滿整個畫面，右下角有上一個／下一個按鈕；按 **✕ 結束** 或 Esc 後全部回到原本的大小與位置。

### 投影

開啟時自動啟動攝影機，可切換攝影機（插拔時清單自動更新）；**↔ 鏡像**左右翻轉（凍結與截圖也會翻轉）；**凍結**、**截圖**。

### 錄影

錄製螢幕畫面，可選擇錄入麥克風聲音並顯示音量。第一次開啟錄影視窗時才會要求麥克風權限，關閉視窗會停止麥克風預覽。

### 設定

工具列位置、預設畫筆顏色、自動隱藏工具列、自動雲端存檔間隔，以及**資料庫使用空間**：顯示總大小佔免費額度 5 GB 的比例與每個存檔的大小，可直接刪除存檔釋出空間。

## 部署到 Cloudflare（管理者）

全部使用 Cloudflare **免費方案**（Workers + Durable Object 內建 SQLite），不需綁定信用卡，也不需另外建立資料庫。

### 事前準備（只需做一次）

1. 註冊 Cloudflare 免費帳號：<https://dash.cloudflare.com/sign-up>（不需信用卡）。
2. 安裝 [Node.js](https://nodejs.org/)（選 LTS 版，18 版以上），安裝時全部按「下一步」即可。

### 步驟 1：（可選）修改網址名稱

用記事本打開 `wrangler.toml`，第 1 行：

```
name = "webscreen"
```

`webscreen` 會成為網址的一部分，可改成你喜歡的名字（只能用**英文小寫、數字和 `-`**），例如 `ming-screen`。

### 步驟 2：在本資料夾打開命令視窗

1. 用檔案總管打開本資料夾（看得到 `wrangler.toml` 那一層）。
2. 點一下上方的**網址列**，把內容改成 `cmd` 後按 Enter，就會在這個資料夾開啟命令提示字元。

### 步驟 3：登入 Cloudflare

```
npx wrangler login
```

- 第一次執行會問 `Need to install the following packages ... Ok to proceed? (y)`，輸入 `y` 按 Enter。
- 瀏覽器會自動打開 Cloudflare 授權頁面，按 **Allow（允許）**。
- 看到 `Successfully logged in` 就完成了，可以關掉該網頁。

### 步驟 4：部署

```
npx wrangler deploy
```

- 第一次使用 Cloudflare Workers 時，會請你設定一個 **workers.dev 子網域**（例如輸入 `mrchang`），請取一個好記的英文名稱。
- 完成後會顯示網址，例如 `https://webscreen.mrchang.workers.dev`，**這就是你的網站網址！**

> 懶人做法：步驟 2～4 也可以直接雙擊本資料夾的 `deploy.bat`，它會自動執行登入與部署。

### 部署時自動完成的事

- 上傳前端網頁（`public/` 整個資料夾）與後端 API（`src/worker.js`）。
- 建立資料庫（Durable Object 內建 SQLite），資料表在第一次使用時自動建立，**不需任何手動設定**。

### 部署後第一件事：設定管理者密碼

第一次部署（或從沒有密碼的舊版更新）後，**請立刻開啟網址設定管理者密碼**。在設定之前，第一個開啟網頁的人可以設定密碼，所以請不要在設定前把網址分享出去。

### 更新程式

修改檔案後，再執行一次 `npx wrangler deploy`（或雙擊 `deploy.bat`）即可更新，既有存檔不會遺失。

## 本機測試與檔案結構（開發者）

### 本機測試

```bash
npx -y wrangler@4 dev
```

開啟 http://localhost:8787 。本機測試的資料只存在電腦上，不會影響線上資料。

> 前端會在開啟時載入各子功能檔案，因此**不能直接雙擊 `index.html` 開啟**，請用本機測試或部署後的網址。

### 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `public/index.html` | 入口頁：依「子功能清單」載入 `features/` 下的各子功能 |
| `public/mindmap/editor.html`、`editor.js` | 心智圖編輯頁（畫面上的心智圖視窗與分享頁面共用） |
| `public/features/<子功能>/` | 每個子功能一個資料夾，內含 `<子功能>.html`（畫面）、`.css`（樣式）、`.js`（程式） |
| `src/worker.js` | 後端 API 與資料庫 |
| `wrangler.toml` | Cloudflare 部署設定 |
| `deploy.bat` | Windows 一鍵部署 |

### 子功能資料夾

| 資料夾 | 功能 |
| --- | --- |
| `auth` | 管理者登入、唯讀模式 |
| `core` | 共用：工具列（所有工具按鈕都在 `core.html`）、視窗系統、管理圖層樣式、音效與共用工具、初始化 |
| `whiteboard` / `background` | 畫筆與白板工具列 / 背景設定 |
| `clock` / `timer` / `scoreboard` / `noise` / `spotlight` / `todo` / `marquee` | 時鐘 / 計時器 / 計分板 / 噪音偵測 / 聚光燈 / 待辦 / 跑馬燈 |
| `note` | 文字便利貼（管理圖層） |
| `lottery` / `wheel` / `dice` / `coin` | 抽籤 / 轉盤 / 骰子 / 硬幣 |
| `browser` / `pdf` / `image` / `html-upload` | 網頁 / PDF / 圖片 / 上傳 HTML（管理圖層） |
| `mindmap` | 心智圖（管理圖層；編輯頁在 `public/mindmap/`） |
| `slideshow` | 依序呈現畫面上的物件 |
| `webcam` / `recorder` | 實物投影 / 螢幕錄影 |
| `settings` / `export-import` | 設定 / 匯出匯入 JSON |
| `cloud` | 雲端存檔、讀檔、分享、自動存檔、新畫面 |
| `startup` | 歡迎畫面與開啟舊存檔 |

- **修改某個子功能**：只要編輯它的資料夾。
- **新增工具按鈕**：在 `core/core.html` 對應分類的 `.sidebar-section` 中加一個 `.sidebar-item`；新增分類則加一個帶 `data-category`、`data-icon` 的 `.sidebar-section`。
- **新增子功能**：建立 `features/<名稱>/` 與三個檔案，把名稱加到 `public/index.html` 的 `FEATURES` 清單。
- 所有子功能共用同一個全域範圍，可直接呼叫其他子功能的函式（例如 `openModal()`、`playTone()`）。

### 後端 API

| 方法與路徑 | 說明 |
| --- | --- |
| `GET /api/saves` | 列出所有存檔 |
| `POST /api/saves?name=名稱` | 新增存檔（body 為畫面狀態 JSON） |
| `GET /api/saves/:id` | 載入存檔 |
| `PUT /api/saves/:id?name=名稱` | 更新存檔 |
| `PATCH /api/saves/:id?name=名稱` | 只修改存檔名稱 |
| `DELETE /api/saves/:id` | 刪除存檔 |
| `GET /api/usage` | 資料庫使用空間 |
| `GET /h/:id/:htmlId` | 直接開啟存檔中上傳的 HTML（沙盒） |
| `GET /m/:id/:mapId` | 心智圖分享頁面（唯讀） |
| `GET /api/mindmaps/:id/:mapId` | 讀取存檔中的單一心智圖 |
| `GET /api/auth/status` | 是否已設定管理者密碼 |
| `POST /api/auth/setup` | 首次設定管理者密碼 |
| `POST /api/auth/login` | 登入（回傳登入憑證） |
| `GET /api/auth/me` | 目前登入身分 |
| `POST /api/auth/logout` | 登出 |

讀取（清單、載入、分享）不需登入；新增、更新、改名、刪除存檔需在請求標頭帶 `Authorization: Bearer <登入憑證>`。

存檔內容以原始文字切塊存入 SQLite（每塊 50 萬字元），讀寫時不解析內容，大型存檔也只需很少的運算時間。
